# Dualocke

Tracker automático del Dualocke de Pokémon Ultra Sol.

- `app/` — programa de Windows. Copia la carpeta a tu PC y abre **Jugar Dualocke.bat** antes de jugar.
- `saves/` — partidas subidas por la app (una por cada guardado).
- `tracker/` — lee las partidas y genera la web.
- Web: https://zjaviiz.github.io/Dualocke/
